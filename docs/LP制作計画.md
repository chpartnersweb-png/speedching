# スピードチング LP制作計画

作成日：2026年10月23日  
対象：既存Astroプロジェクト  
今回の成果物：デザイン・構成・画像生成・アニメーション・実装の計画。サイト本体の実装、画像生成、依存パッケージの変更、公開はこの段階では行わない。

## 1. 制作方針

**「夜の街で見つける、スピードチングの電話看板」**をコンセプトにする。

いただいたネオン調チラシの色と勢いを、スマートフォンで読みやすい電話予約のページへ置き換える。軽トラックの実車写真を主役にし、地域のお店らしい親しみと、連絡の取りやすさを伝える。

閲覧直後に「代行運転のお店」「電話番号」「通常の営業時間」「事前予約なら年中受付」が分かることを優先する。料金・対応エリアを確認したい人には、そのまま電話で相談できる導線を用意する。

装飾は看板文字、細いネオン線、夜の路面の色に絞る。高級感を演出する大きすぎる余白、長い導入文、英語の装飾見出し、同じ形の特徴カードの反復は採用しない。

### LenisとGSAPの判断

- Lenisは使用しない。ブラウザ標準のスクロールで操作できる設計にする。
- GSAPは、見出し周囲の装飾と下層の軽い登場表現に使用する。
- 依頼文後半の「gsapやlenisを使用」は、前半の具体的な希望「Lenisはアンインストールもしくは使わない」を優先し、GSAPのみ採用する方針とする。
- 現在は両方とも依存関係に含まれる。計画段階では変更しない。実装時もLenisを読み込まなければよく、依存関係の整理を行う場合にアンインストールする。

## 4. ビジュアル設計

### 配色案

以下はチラシから着想した初期案。厳密な色の抽出値ではなく、実装時に文字のコントラストを確認して調整する。

| 役割 | 色案 | 主な用途 |
| --- | --- | --- |
| 夜の背景 | `#0B111B` | ページ全体 |
| 少し明るい濃紺 | `#162233` | 営業案内・情報表の背景 |
| 白に近い文字 | `#F5F7FA` | 本文、営業時間、電話番号の基本色 |
| 水色 | `#6DECF2` | 「スピード」、区切り線、操作時の輪郭 |
| ピンク | `#FF69DB` | 「代行運転」の小看板、限定した装飾線 |
| オレンジ | `#FFB45B` | 「チング」、電話ボタンの背景、事前予約の強調 |

背景の大半は落ち着いた濃紺にする。ピンク・水色・オレンジは文字と線に集約し、本文には発光を付けない。電話ボタンはオレンジ地に濃紺文字で、光らせなくても判別できる状態にする。

### 文字と形

- 日本語は太めの角ゴシックを中心にする。まずシステムフォントで組み、必要なら日本語Webフォントを見出し用の1系統に限定する。
- 正式名称は常に「スピードチング」。ロゴ風の見出しでは「スピード」を水色、「チング」をオレンジに分けて見せる。
- 店名はPCで約64〜88px、スマートフォンで約36〜44pxを目安にし、320px幅でも画面内に収める。
- 本文は16〜18px、行間は1.7前後。電話番号は数字を大きく、字間を詰めすぎず表示する。
- 見出しの下に細い線を引く。看板らしい力強さは文字の太さと配置で表現し、立体加工や強い傾斜を多用しない。
- ボタンや情報欄の角は小さめに丸める。線・情報表・横長の帯を中心に組む。

## 5. ページ構成とコピー案

ページ全体は6つのまとまりで構成する。長いスクロールを前提にせず、営業・予約情報を上から順に重複なく伝える。

### ① ヘッダーとファーストビュー

**役割：お店を識別し、その場で電話できる。**

ヘッダーには店名と電話ボタンを置く。PCでは「営業案内」「車のお預かり」「店舗情報」のページ内リンクを追加する。スマートフォンでは常設する情報を店名と電話に絞り、メニューを開かなくても予約できるようにする。

ファーストビューのコピー案：

> 大分市の代行運転  
> **スピードチング**  
> **すぐに駆けつけます。**  
> 金・土・日・祝 20:00〜翌3:00  
> **事前予約にて年中受付しております。**  
> 電話で予約・相談する  
> **080-3957-6137**

- PC：左側約55%を看板文字と電話、右側約45%を実車写真にする。写真の縦長比率を生かし、無理に横長へ引き伸ばさない。
- スマートフォン：店名・営業時間・事前予約・電話を先に表示し、その下に実車写真を配置する。高さの小さい端末でも写真より先に予約情報が届く順序にする。
- 写真と文字の間には水色の細い線を使い、チラシの印象をつなぐ。
- 画面いっぱいの高さを強制せず、文字量と写真に合わせて高さが伸びる構成にする。

### ② 営業案内と年中受付の予約案内

**役割：通常の営業日と事前予約を区別して理解できる。**

同じ高さの特徴カードを並べる構成にはせず、横長の営業案内板としてまとめる。

> 通常営業  
> **金・土・日・祝　20:00〜翌3:00**  
> 定休日：月曜日〜木曜日  
> **事前予約にて年中受付しております。**  
> ご希望の日時は、お電話でご相談ください。

「年中受付」を小さな注記へ追いやらず、通常営業時間と同じまとまりの中で大きく扱う。受付時間、予約の締切、祝日の扱いが確認できた段階で補足する。

### ③ 車のお預かり

**役割：代行運転以外に相談できる内容を伝える。**

見出し案は **「車のお預かりも、やっています。」**。

横幅の広い文章エリアに短い説明を置き、右側または下部に「お預かりについて電話で相談する」を配置する。小さな車の線画はSVGで作り、写真のない保管場所を実在するように見せない。

預かり料金、期間、受け渡し条件は不明なため、「無料」「何日でも」「屋根付き」「24時間出入庫」といった表現は追加しない。独立した写真セクションを増やすためだけの画像生成も行わない。

### ④ 電話でのご相談とご利用案内

**役割：初めてでも何を伝えればよいか分かる。**

見出し案は **「まずは、お電話ください。」**。

横方向の細い線に、3つの短い案内を順番に配置する。スマートフォンでは縦につなぐ。

1. **電話する**：080-3957-6137へ。
2. **希望を伝える**：ご希望の日時・お迎え場所・行き先をお聞かせください。
3. **内容を相談する**：料金や対応可否などはお電話でご確認ください。

これは利用者が相談しやすくなるための案内案。実際の受付手順に合わせて最終調整する。「必ず配車できる」など、受付結果を先に約束する表現にはしない。

すぐ下に「お支払い：現金」を短く掲載する。料金未確定の段階では価格表を作らず、「料金・対応エリアはお電話でご確認ください」と案内する。チラシの条件が確認できれば、ここに簡潔な料金表と対応エリアの文章を追加する。

### ⑤ 店舗情報

**役割：所在地と連絡先を確認できる。**

店名、電話、住所、最寄駅、営業時間、定休日、支払方法、駐車場を罫線付きの情報表で表示する。PCは表の左右に余裕を持たせ、スマートフォンは項目名と内容が自然に折り返す幅にする。

住所が町名までのため、正確な地図ピンやアクセス経路は現時点で作らない。番地または正式な地図URLが確認できたら地図リンクを追加する。「牧駅から徒歩8分」は提供情報として掲載し、独自の経路説明は加えない。

### ⑥ 最後の予約案内とフッター

**役割：読了した人が迷わず電話できる。**

生成する夜の路面画像を背景の一部に使用し、濃紺のオーバーレイで文字の読みやすさを保つ。

> **事前予約にて、年中受付。**  
> 代行運転・車のお預かりのご相談は  
> **スピードチング　080-3957-6137**  
> 金・土・日・祝 20:00〜翌3:00

電話ボタンの近くにも通常営業時間を併記する。フッターは店名と必要な基本情報に絞る。

## 7. 画像生成計画

### 基本方針

追加生成はまず1点に絞る。チラシの雰囲気に合わせた「夜の路面とネオンの反射」を作り、下部の予約案内の背景に使用する。実車写真と同じ重さの架空の車両写真を増やすより、手元の実物を主役にした構成にする。

生成画像の目的は夜の雰囲気の補助。実際の大分の街並み、営業所、保管場所、スタッフ、随伴車として説明しない。ページに意味のある写真として掲載する場合は「イメージ画像」と分かる扱いにし、装飾背景として使用する場合は読み上げ対象にしない。

### 生成する画像

| 項目 | 仕様案 |
| --- | --- |
| 用途 | 最後の予約案内の背景 |
| 参考素材 | `line_oa_chat_261021_103632.jpg`。色と夜の雰囲気の参考のみ |
| 内容 | 夜の道路の低い目線。水色・ピンク・暖色の看板光が控えめに路面へ反射する |
| 構図 | 横長約3:2で生成し、PCでは横帯へトリミング。中央は暗く、文字を載せても干渉しない |
| モバイル | 中央の狭い範囲でも成立する構図。必要なら縦用を追加生成するが、まず1点で検証する |
| 避ける要素 | 読める看板、ロゴ、車のナンバー、人物、特定の建物、豪華な外国の繁華街、速度感の強い光跡 |
| 保存先案 | `src/assets/generated/night-road-reservation-v1.png`。配信時は最適化する |

## 8. アニメーション計画

「夜の看板が静かに灯る」程度の動きにする。電話番号・営業時間・予約ボタンは初期表示から利用できる状態に保つ。

| 対象 | 動き | 目安 | 実装 |
| --- | --- | --- | --- |
| 店名まわりの細いネオン線 | 左から一度だけ伸びる | 0.45〜0.6秒 | GSAP、`scaleX` |
| 店名の装飾光 | 発光量が一度だけ落ち着く。文字本体は常に見える | 0.5秒前後 | 装飾要素のopacityのみ |
| 下層の見出し・相談案内 | 小さな移動とフェードで一度だけ登場 | 8〜12px、0.35〜0.45秒 | GSAP＋ScrollTrigger |
| 電話ボタン | ホバー・フォーカスで枠と背景が変わる | 0.15秒前後 | CSS |
| 実車写真・生成背景 | 静止 | 常時 | 視認性と軽さを優先 |

- `gsap.matchMedia()`で幅と`prefers-reduced-motion`を扱う。動きを減らす設定では登場移動や発光の変化を停止する。
- スマートフォンの移動量は最大8px程度に抑える。営業案内と電話操作部分はスクロール演出の対象から外す。
- 通常のHTML/CSSで内容を表示しておき、JavaScriptの初期化失敗によって本文が透明なまま残らない実装にする。
- ネオンの点滅、常時揺れる電話ボタン、車の疾走、横スクロール、スクロールの固定、ローディング画面は入れない。
- ページ内移動もブラウザ標準を基本にし、スクロール操作をGSAPやLenisへ置き換えない。

## 9. 実装方針

現状はAstroの初期ページ。`package.json`にはAstro、GSAP、Lenisがあり、実装済みのLPはまだない。

### 構成案

```text
src/
  pages/index.astro                 ページ構成・メタ情報
  components/PhoneLink.astro        各所で使う電話リンク
  components/Hero.astro             看板文字と実車写真
  components/BusinessInfo.astro     営業・店舗情報
  data/site.ts                     店名・電話・営業時間など
  styles/global.css                配色・文字・共通レイアウト
  scripts/motion.ts                GSAPの装飾・登場処理
  assets/generated/                採用した生成画像
```

- Astroの静的な1ページとして構成する。React等のUIフレームワークは追加しない。
- 予約は電話リンクで完結する。予約フォーム・LINE予約・問い合わせデータの保存は追加しない。
- 店舗情報と電話番号を1か所で管理して表示の食い違いを防ぐ。
- 共通の色や文字はグローバルCSS、各コンポーネント固有の配置はAstroのスコープ付きスタイルを使う。
- 実車写真・生成画像は`astro:assets`の`Image`や`Picture`で最適化し、適切な画像幅と縦横比を指定する。主写真は優先表示し、下部の画像は遅延読み込みする。
- 最初の表示はJavaScriptに依存させず、GSAPは動きに必要な部分だけで使用する。
- 本文のコントラスト、キーボードフォーカス、電話ボタンの押しやすさを確認する。操作領域は高さ48px以上を目安にする。

- canonical、OGPのURL、sitemapは公開先が決まってから設定する。構造化データを追加する場合も、住所・営業時間・サービス情報は確認済みの内容に限定する。

## 11. 制作と確認の順序

1. 本計画の配色・コピー・実車写真の扱いを制作基準にする。
2. 夜の路面の背景画像を1点生成し、PC・スマートフォンでの切り取りを確認する。
3. 最初に店名、実車写真、通常営業、年中受付、電話ボタンを実装する。
4. 営業案内、車のお預かり、相談案内、店舗情報、最後の電話導線を組む。
5. レスポンシブ調整後に、GSAPの控えめな動きを追加する。
6. 公開用の文章へ確認済み情報を反映する。未確認の料金・地図等は推測で追加しない。
7. 実装後、`npm run build`とPC・スマートフォンの表示確認を行う。

### 実装後の確認項目

- 320／390／768／1024／1440px幅で、横方向のはみ出しがない。
- スマートフォンで写真を待たずに電話と営業案内へ到達できる。
- すべての電話リンクが`tel:08039576137`で統一されている。
- 通常営業と「事前予約にて年中受付」を混同させる表記がない。
- 固定電話バーがページ最下部、フォーカス位置、端末のセーフエリアを隠さない。
- 動きを減らす設定、JavaScript無効時も情報と電話リンクを使える。
- 実車写真が不自然に切れず、生成画像が実際の設備・車両・場所と誤解されない。
- 未確認の価格、対応エリア、認定表記、保証、口コミ等が入り込んでいない。

開発サーバーが必要な際は、このプロジェクトのAGENTS.mdに従い`astro dev --background`を使用し、`astro dev status`／`astro dev logs`／`astro dev stop`で管理する。コマンドが導入済みバージョンで使えるかは実行時に確認する。
