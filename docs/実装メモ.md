# スピードチング LP 実装メモ

実装日：2026年10月23日

## 実装内容

- 提供チラシの水色・ピンク・オレンジを取り入れた、濃紺の1ページLP。
- 実際の軽トラック写真を使用したファーストビュー。
- 通常営業と「事前予約にて年中受付」の営業案内板。
- 車のお預かり、電話の相談案内、現金払い、店舗情報。
- ヘッダー・本文・ページ末尾からの電話リンク。
- 幅767px以下の固定電話バーと端末セーフエリアへの余白。
- PC・タブレット・スマートフォンに応じたレイアウト。
- GSAP／ScrollTriggerによる看板の下線と下層の軽い登場処理。
- 動きを減らす設定、キーボードフォーカス、本文へのスキップリンク。
- タイトル、description、基本OGP、軽トラックのSVGファビコン。

Lenisは使用していない。依存関係には残しているが、コードからのimportや初期化は行っていない。依存パッケージの追加・削除は行っていない。

## 生成画像

組み込み画像生成ツール（imagegen）で生成。

- 採用画像：`src/assets/generated/night-road-reservation-v1.png`
- 参考素材：`src/assets/line_oa_chat_261021_103632.jpg`
- 使用箇所：ページ末尾の予約案内の装飾背景。
- 実在する街並み・営業所・預かり施設の写真としては使用していない。
- 元の実車写真・チラシはそのまま保存している。

## 確認状態と再開方法

ユーザーの「実装後の確認は自分で行うので、不要です」という指定に従い、ビルド、型チェック、ブラウザ確認、スクリーンショット取得は実施していない。開発サーバーも起動していない。表示・動作・ビルド結果は未確認。

表示を確認する際は、プロジェクトルートで以下を実行する。

```powershell
npm run dev -- --background
```

AGENTS.mdに沿った管理コマンド：

```powershell
npm run astro -- dev status
npm run astro -- dev logs
npm run astro -- dev stop
```

確認時の主なポイントは、スマートフォンの電話バー、写真の切り取り、店名と電話番号のはみ出し、ページ内リンク、通常営業と事前予約の表示。必要に応じてユーザー側で`npm run build`を実行する。

## 掲載を保留した情報

チラシの料金・対応エリア・追加の訴求表現は、現行条件が未確認のため掲載していない。住所は提供された町名までを表示し、正確な位置を断定する地図ピンは追加していない。公開先が未指定のため、canonical・OGPの絶対URL・sitemap設定は保留。

実車写真の人物の掲載可否、祝日と定休日が重なる場合の扱い、事前予約の受付条件等は、制作計画書の確認項目に記載している。
